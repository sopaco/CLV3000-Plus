# CLV3000 Plus

**让 AI 帮你写代码，别让临时项目占满你的硬盘。**

你用 Claude Code、Cursor、Codex、WorkBuddy、Deepseek Harness 或其他 Coding Agent 做过小实验吗？  
很可能已经攒下不少「当时觉得有用、后来再也没打开过」的项目文件夹——每个都带着缓存、依赖和 Agent 留下的痕迹，悄悄吃掉几十 GB 空间。

CLV3000 Plus 是一款装在电脑上的清理工具，专门帮**正在用各类 Coding Agent 的准技术 / 非技术朋友**理清这些烂摊子：哪些可以删、占了多少空间、删之前让你看清楚再动手。

> 全程在本地运行，不上传你的文件路径，也不需要联网。

### 绿色轻量，快得离谱

不臃肿、不拖慢电脑。CLV3000 Plus 采用与 **Codex 同源**的高性能 **Rust** 技术构建——同类工具里运行速度数一数二，内存占用极低。哪怕是几年前的老电脑，打开、扫描、清理也能快得飞起。

## 它能帮你做什么

### 🤖 找出 Agent 留下的试验项目

自动识别由 Coding Agent 创建或标记过的项目，例如：

| 常见工具 | 识别方式（你不需要懂这些） |
|---------|--------------------------|
| Claude Code | 项目里的 `.claude/` 等痕迹 |
| Cursor | `.cursor/` 等配置目录 |
| Codex | `.codex/` 等标记 |
| WorkBuddy | `.workbuddy/` 等标记 |
| 其他 Agent | 项目名、配置文件等特征 |

扫描后你会看到一张清单：**项目名称、占多大空间、为什么被识别出来、多久没动过**。一目了然，再决定留还是删。

### 🧹 安全地清理缓存和依赖

除了 Agent 项目，还会帮你找出各技术栈的构建缓存和依赖目录（如 `node_modules`、`target` 等）。  
每一项都标注了**安全等级**，简单模式下默认只勾选「放心可删」的内容——用人话解释，不堆术语。

### ⚡ 其他实用功能

- **一键体检**：扫一遍常用目录，汇总可释放空间
- **启动项管理**：减轻开机负担（macOS / Windows）
- **进程查看**：找出占用内存过高的程序

## 使用流程

第一次打开会有简短引导，选「简单模式」即可，全程不需要技术背景。

### 1. 欢迎与模式选择

打开应用，按提示选择**简单模式（推荐）**——每一项都会用日常语言说明，默认只清理安全内容。

### 2. 一键体检

点击 **「立即体检」**，工具会扫描你电脑上的常见工作目录（如文稿、桌面、项目文件夹等），找出可清理项和 Agent 试验项目。

### 3. 查看 Agent 项目

体检完成后，进入 **「Agent 项目」** 页面，浏览被识别出的试验项目。可以按名称搜索，查看每个项目占用的空间和识别原因。

### 4. 勾选并清理

在清理页面勾选你想删除的项目，确认后执行。删除前会再次提示释放空间大小；支持软删除（先进回收站），给你反悔的余地。

### 5. 完成，空间回来了

清理完成后，仪表盘会更新可释放空间和磁盘使用情况。建议每隔一两周体检一次，别让 Agent 试验项目悄悄堆满硬盘。

## 常见问题

**Q：会删掉我正在用的项目吗？**  
A：简单模式下默认只勾选安全项；近期有改动的项目会标为「谨慎」，不会默认选中。删除前还有确认步骤。

**Q：我的代码会被上传到云端吗？**  
A：不会。所有扫描和清理都在本机完成，不联网、不收集数据。

**Q：支持哪些 Coding Agent？**  
A：目前已覆盖 Claude Code、Cursor、Codex、WorkBuddy 等主流工具，并持续扩展更多 Agent 的识别规则。

**Q：删错了怎么办？**  
A：默认使用软删除（文件先进回收站），7 天内可以恢复。

## 开发者

本项目使用 Rust + GPUI 构建。如需从源码运行或打包：

```bash
# 需要 macOS Metal Toolchain（Xcode）
# xcodebuild -downloadComponent MetalToolchain

cargo run -p clv-app
```

### macOS 打包（.app + .dmg）

```bash
./scripts/bundle-macos.sh
# 产物：
#   target/release/CLV3000 Plus.app
#   target/release/CLV3000 Plus.dmg
```

### Windows 打包

```powershell
cargo build -p clv-app --release
# 产物：target\release\clv3000-plus.exe
```
