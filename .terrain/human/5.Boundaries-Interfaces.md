# System Boundaries and Interfaces

This document catalogs every way external actors—users, the operating system, or embedding code—interact with CLV3000 Plus. The app is a desktop GUI utility with no REST API or CLI subcommands; its boundaries are the window UI, system tray, persisted JSON configuration, and the public Rust library surface of `clv-core`.

---

## Desktop GUI

The primary interface is the GPUI main window launched from `crates/clv-app/src/main.rs`. Navigation happens through sidebar pages defined in `AppPage` (`crates/clv-app/src/app/state.rs:23-51`):

| Page | Purpose |
|------|---------|
| Dashboard | Disk health, scan trigger, cleanup history |
| Cleanup | Select and delete scan findings |
| Agent | Review AI experiment projects |
| Large Files | Browse large files found during scan |
| Startup | Manage OS startup items |
| Process | View and kill processes |
| Settings | Preferences and scan path editor |
| Onboarding | First-run setup wizard |

---

## System Tray

Implemented in `crates/clv-app/src/tray.rs`. Available when `TrayController::install` succeeds at startup (`main.rs:37`).

| Menu action | Behavior | Source |
|-------------|----------|--------|
| Open | Activates or creates main window | `TrayAction::Open` — `tray.rs:12` |
| Scan | Sets atomic scan flag polled by `ClvApp` | `request_scan()` — `tray.rs:30` |
| Quit | Exits application | `TrayAction::Quit` |
| Double-click icon | Same as Open | `tray.rs:67-72` |

The tray tooltip updates when disk usage refreshes via `TrayController::set_tooltip`.

## Configuration (`AppSettings`)

Persisted to `settings.json` under the app config directory (`crates/clv-core/src/settings/mod.rs:48-87`).

| Field | Type | Default | Meaning |
|-------|------|---------|---------|
| `scan_paths` | path list | `~/Projects`, Documents, Desktop | Directory roots for project artifact scanning |
| `expert_mode` | bool | `false` | Show full paths; allow cleaning Protected-risk items |
| `soft_delete` | bool | `true` | Move to app trash instead of permanent delete |
| `soft_delete_days` | u32 | `7` | Auto-purge trash files older than N days |
| `include_agent_heuristics` | bool | `true` | Include agent session/cache directories in scan |
| `auto_scan_weekly` | bool | `false` | Weekly auto-scan preference (reserved) |
| `onboarding_done` | bool | `false` | Whether first-run wizard completed |
| `language` | enum | System locale | UI language: zh / en / ja |
| `theme` | enum | Default | Color theme selection |

**Example** (conceptual):

```json
{
  "scan_paths": ["/Users/me/Projects"],
  "expert_mode": false,
  "soft_delete": true,
  "soft_delete_days": 7,
  "include_agent_heuristics": true,
  "onboarding_done": true,
  "language": "En",
  "theme": "Default"
}
```

## Integration Notes

- **Headless automation**: Add `clv-core` as a dependency and call `Scanner` + `CleanupExecutor` directly—no GPUI required.
- **CI/CD**: Invoke the compiled binary or library; there are no HTTP hooks.
- **macOS distribution**: Use `scripts/bundle-macos.sh` to produce an `.app` bundle.
- **Trust boundary**: All write operations target app config dir and user-selected cleanup paths only; system paths are hard-blocked in `paths.rs:165`.
